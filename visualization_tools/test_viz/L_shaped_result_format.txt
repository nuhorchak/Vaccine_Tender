Indices 
a => antigens
v => vaccines
p => producers
t => time periods
tau => time periods for the end of the tenders
w (omega) => scenarios

L_shaped_output is a dictionary 
keys = ["F","Y","W","L","Q","X","I","Vc","S"]
values
"F" => binary, tender schedule => F[a][t][tau]
"Y" => binary, manufacturers producing in period t => Y[p][t]
"W" => binary, manufacturers if they participate in a tender => W[p][t][tau]
"L" => integer (btw 0 and 5), capacity extension decision => L[p][t]
"Q" => continuous, commitment amounts => Q[v][p][t][tau]
"X" => continuous, production amounts => X[v][p][t]
"I" => continuous, inventory level => I[v][t][w]
"Vc" => continuous, vaccinated children => Vc[v][t][w]
"S" => continuous, unvaccinated children => S[a][t][w]
